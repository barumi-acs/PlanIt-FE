# 🪐 PlanIt-FE

AI 기반 자기계발 투두리스트 웹 애플리케이션

---

## 📌 Overview

PlanIt은 사용자의 목표 달성을 돕기 위한  
자기계발 중심의 할 일 관리 서비스입니다.

일간/주간/월간 단위의 일정 관리와  
친구 기능, 리포트 분석을 통해  
지속적인 동기 부여와 성취 관리를 지원합니다.

---

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Context API
- Custom Hooks

---

## ✨ Main Features

- 📅 Daily / Weekly / Monthly 할 일 관리
- 👥 친구 기능
- 🤖 AI 기반 할일 생성
- 📊 AI 기반 패턴 분석 리포트

---
